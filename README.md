# BackGround-CSS

A background animation is a visual effect applied to the background of a webpage to make the UI more dynamic and attractive. It can be created using CSS animations, CSS transitions, JavaScript, Canvas, SVG, or animation libraries.

Common examples include:

Animated gradients
Moving particles
Floating shapes
Background images moving or zooming
Color-changing backgrounds
Parallax effects
Animated waves or blobs
